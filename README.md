### gratheon/robotic-beehive
[Gratheon Robotic beehive]([https://gratheon.notion.site/Robotic-Beehive-fd9559a2950b44bc8291972299ced18e](https://gratheon.com/about/products/robotic_beehive/)) is a project to develop a robotic beehive that can be used to inspect beehives

#### Functionality
- move hive section up/down


#### Components
- NVidia Jetson Nano
- Display
- 2 stepper motors on a rail
- DM542 stepmotor controller
- 24V power supply
